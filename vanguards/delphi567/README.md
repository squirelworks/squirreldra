# Delphi 5/6/7 support

Scaffold and notes for Delphi 5/6/7 analysis helpers (RTTI recovery, VMT reconstruction, calling conventions, Ghidra scripts, etc.).

## Layout

```
delphi567/
├── scripts/       # Ghidra scripts and helpers
├── docs/          # Detailed notes
├── knowledge/     # Reference material
├── examples/
├── patches/
├── deps/          # Vendored tool notes (dhrake, undelphi, DelphiReSym, IDR)
├── notes/
└── sigs/
```

## Status

Active scaffold with documentation and scripts. Dependency checkouts live under `deps/` (large `.git` trees are not fully mirrored here).
