# The Eight Commands

| Command | Meaning |
|---------|---------|
| `>` | Move pointer right |
| `<` | Move pointer left |
| `+` | Increment cell |
| `-` | Decrement cell |
| `.` | Output cell |
| `,` | Input cell |
| `[` | Jump past matching `]` if cell is zero |
| `]` | Jump back to matching `[` if cell is non-zero |

Everything else is a comment. This includes your attempts to understand the program.

## Why Ghidra?

No good reason. The tape is usually 30,000 bytes. The control flow is a single pointer. Function ID will not help.
